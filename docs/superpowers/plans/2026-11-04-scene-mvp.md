# Cozy scene MVP Implementation Plan

**Goal:** Deliver one editable cozy room and a working idle → greeting → finishing → idle interaction with Vivi.
**Architecture:** A Blender-exported environment, existing retargeted animation clips, and a pure state controller feed a Three.js scene. Character-specific mapping is isolated from action timing and room layout.
**Tech Stack:** Blender, GLB/VRM, Three.js, three-vrm, Vite, Node tests, Playwright.

Work in the existing isolated worktree, preserving the character lab and prior studies. User authorization covers implementation and local preview; no purchase or deployment.
